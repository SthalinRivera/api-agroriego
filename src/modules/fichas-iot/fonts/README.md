# Fuentes PDF integradas

Lato Regular y Bold, sin modificar, de https://github.com/google/fonts/tree/main/ofl/lato. Licencia SIL OFL 1.1 en OFL.txt.

Los bytes TrueType se guardan en base64 en lato.json y se importan estáticamente. No se descargan ni se buscan fuentes externas al generar el PDF. PDFKit incrusta los glifos utilizados.

- Lato-Bold.ttf: 8a0aace75d33794eece4b28187bfc1df0bbd2888b5d8a56e01788c8d65d16be1
